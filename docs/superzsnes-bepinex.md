# SUPER ZSNES : la documentation a déménagé

Tout ce qui était ici est maintenant dans **[docs/superzsnes/](superzsnes/README.md)**, découpé en
dix fichiers (architecture, BepInEx, patchs, options, intérieur de l'émulateur, méthode de
rétro-ingénierie, runbook après mise à jour, build et test, journal des mesures).

Ce dossier est **embarqué dans `SuperZsnes.dll`** et déployé dans chaque dossier d'émulateur sous
`BepInEx\nixx-docs\`, pour que le runbook soit à côté du journal le jour où une mise à jour casse
quelque chose.
