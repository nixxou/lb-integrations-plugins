In short

Flycast is the emulator for Sega's Dreamcast and for the arcade boards built on the same hardware. One emulator covers four LaunchBox platforms: Sega Dreamcast, Sega Naomi, Sega Naomi 2 and Sammy Atomiswave. Flycast also runs Sega System SP games; LaunchBox has no platform for those, but if you create one yourself with "System SP" anywhere in its name, the plugin treats it as a Flycast platform too.

LaunchBox does not know Flycast on its own. The Nixx-Flycast plugin fills that gap: it downloads and updates Flycast for you, sets up the emulator entry with the right platforms, tells LaunchBox which BIOS files are needed, passes your RetroAchievements login, gives Flycast keys to save and load states and to quit, lets LaunchBox see and back up your saves, and adds a per-game options window. It also helps LaunchBox's Import ROM Files wizard when you import a big arcade (MAME) folder.

Getting started

Installing Flycast

  • In LaunchBox, open Tools > Manage > Emulators, click Add, and pick Nixx-Flycast in the list. Click the download button: the plugin fetches the latest Windows release of Flycast from its official GitHub page.
  • Flycast is installed into LaunchBox\Emulators\Nixx-Flycast. The emulator entry is created with its four platforms already ticked as default emulator, and launches games in fullscreen.
  • Pressing download a second time does not create a second entry: the existing one is reused.
  • When a newer Flycast is released, LaunchBox shows an update for it. Updating unpacks the new version over the old one and never empties the folder first, so your memory cards, save states and settings stay.

Already have Flycast?

You can also add a Flycast you installed yourself, by hand. As long as the entry points to flycast.exe, the plugin recognises it, adds the missing Flycast platforms to it (it never removes or unticks a platform you set), and fills empty save/load/exit pause-screen scripts.

BIOS files

The plugin tells LaunchBox which BIOS files each platform needs, so LaunchBox can show you what is missing. Put them in Flycast's data folder (Emulators\Nixx-Flycast\data):

  • Dreamcast: dc_boot.bin (or dc_bios.bin). Optional: without it, Flycast uses its own built-in BIOS, which runs most games. A few games refuse it and need the real one.
  • Naomi: naomi.zip, required (234 of 244 titles). A few games want their own BIOS as well: hod2bios.zip, f355bios.zip, f355dlx.zip, airlbios.zip, naomigd.zip, naomidev.zip.
  • Naomi 2: naomi2.zip, required.
  • Atomiswave: awbios.zip, required.

Importing games

  • Dreamcast games: .chd, .gdi, .cdi or .cue (and .elf homebrew).
  • Arcade games: MAME romsets as .zip or .7z, kept zipped. Flycast reads the zip itself, so the plugin turns LaunchBox's automatic extraction off.
  • When you use Import ROM Files and choose Nixx-Flycast as the emulator, the plugin helps the wizard:
    • On the last page, the game list keeps only the games of the chosen platform. Handy when you point it at a whole MAME folder, most of which is not Naomi or Atomiswave. While LaunchBox fills the list (it can take a minute), a small window tells you it is working.
    • For an arcade platform, "Force using MAME metadata" is ticked for you, and the MAME page's "Skip..." boxes are unticked (Flycast runs quiz and mahjong games, and many sets MAME calls unplayable). You can tick them back.
    • Once the list is sorted, the Back button is greyed: finish or cancel from there.
    • After the import, some arcade sets that LaunchBox silently drops (for example vf4b next to vf4, both "Virtua Fighter 4") are added back as versions of their game. Nothing LaunchBox imported is changed, and your choices on the MAME page are respected.
  • How strict that list check is can be set per platform (see Options).

Playing a game

Select a game and click Play. Before Flycast starts, the plugin:

  • writes your RetroAchievements login into Flycast's settings, if LaunchBox has one (and hardcore mode if you turned it on for the emulator). If that fails, the game still starts;
  • makes sure Flycast has the save state and quit keys (see Saves);
  • applies the game's own options, if you set some in the Options window. They are given to Flycast for this session only.

For a Naomi GD-ROM game (a zip plus a disc image), if the disc image is missing the plugin does not start Flycast. It shows a message instead, saying which .chd file is needed and in which folder to put it (a folder named after the set, next to the zip). The zip only holds the game's security key; the game itself is on the disc image.

Only one Flycast game can be launched at a time. A second launch while one is still running is refused (silently if it is a double click, with a message otherwise). A launch is also refused if Flycast is already open on its own.

When you quit, use Escape (or LaunchBox's Exit): Flycast closes cleanly and finishes writing its memory card. If the plugin had to set aside part of the game's own Flycast config for the session, it puts it back once Flycast has closed. If LaunchBox or the PC stopped in the middle, this is done at the next launch, at the next LaunchBox start, or when you open Flycast without a game.

Options

Per game: right-click > Nixx-Flycast : Options...

Right-click a game (or a selection of games) > Nixx-Flycast : Options.... This entry is added by the pack's small helper plugin Nixx-Menus; it shows in LaunchBox, not in Big Box. It appears for games whose emulator is a Flycast, or whose platform one of your Flycast entries runs.

  • Three tabs of settings, with Flycast's own names: Video (renderer, internal resolution, filtering, widescreen, integer scaling, VSync, FPS counter...), Rendering (frame skipping, shadows, fog, framebuffer emulation...), and System (region, Dreamcast language, broadcast, cable, CPU clock, volume, HLE BIOS, fast GD-ROM loading, 32 MB RAM mod, Naomi free play...).
  • Everything starts on Default: what the game runs on without the plugin (its own Flycast game config if you made one in Flycast, else Flycast's settings). A list shows <Default : value>, a checkbox has a third "filled" state for default, a number has an "Override default" box. Only what you change is kept, so opening the window changes nothing.
  • A colored bar beside each setting tells you where its value comes from: set here, from the game's own Flycast config, or from Flycast's settings. Reset to defaults puts everything back on default.
  • What you set here wins over the game's own Flycast config for the session. Flycast's built-in fixes for known games still win over it.
  • A setting that only means something for the Dreamcast (cable, language...) or for arcade games is marked so when your selection mixes both, and is only given to the games it applies to.
  • Several games with different settings: a list at the top lets you pick which one to start from. OK applies what is shown to all selected games, after asking.
  • Advanced tab: shows the exact lines given to Flycast. Tick "Edit by hand" to write your own (Flycast's section and key names); the other tabs are then not used. Preview result... shows the command line Flycast will be started with.
  • Delete game config (only shown when the game has one): deletes the game's own Flycast config, the same as Flycast's "Delete Game Config". This is done right away, after asking, not on OK. It does not touch the plugin's own settings for the game, and it is refused while Flycast is running.

Your Flycast settings file is never rewritten for these options: they are passed to Flycast for each session only.

Plugin settings: Tools > Nixx Integration Plugins Configuration...

The pack's window has a General tab and one tab per plugin. The Flycast tab holds the Import ROM Files settings:

  • Quick check (on by default), per platform: the game list keeps a file by its name, the way Flycast finds a set (a Dreamcast disc by its extension). Instant.
  • CRC check (off by default), per platform: checks the files' content. A set must contain all its files; a set under the wrong name is recognised and the list tells you what to rename it to; each game is test-loaded the way Flycast loads it. This can take minutes on a whole MAME folder, under a window you can cancel.
  • After the import, put back the arcade sets LaunchBox left out (on by default): see Importing games.

Below them, Flycast's system settings - every game: region, Dreamcast language, broadcast, cable, SH4 clock, volume, DSP, HLE BIOS, fast GD-ROM loading, 32 MB RAM mod and Naomi free play. These are Flycast's own settings (its emu.cfg), the same as in Flycast's Settings window: only what you change is written, and only while Flycast is closed. A game's own options (its right-click menu) and a game's own Flycast config still win over them for that game. "Your console" sets the Dreamcast language here too.

Saves and save states

LaunchBox's save management sees your Flycast saves, can back them up and restore them. Everything lives in Flycast's data folder (Emulators\Nixx-Flycast\data), unless you redirected folders in Flycast's settings, which the plugin follows.

  • Dreamcast: the game's memory card (VMU in port A1). Flycast names it after the disc's product number, read from the disc image, so it is found whatever the file name of your game.
  • Arcade games: the board's saved data (high scores, settings, card files), named after the game's zip. A backup, restore or delete always takes the whole set of files together.
  • Save states: 10 slots (0 to 9) per game, named after the game's file.
  • A memory card coming from Argosy (named <id>.A1.bin) is restored under the name Flycast actually reads.

Keys

Flycast ships with no key to save or load a state, and none to quit. On install (or at first launch for a Flycast you added yourself), the plugin adds them:

KeyAction
F2Save state
F4Load state
F6 / F7Previous / next state slot
EscapeQuit Flycast

Flycast's normal controls are kept. A key you already use is never taken, an action you already bound keeps your key, and a keyboard mapping file you already have is never rewritten. The emulator entry's pause-screen scripts (save state, load state, exit) are filled with the keys Flycast really has, so LaunchBox's and Big Box's pause screen work. Only empty scripts are filled.

Limits and things to know

  • Shared memory cards are left alone. Flycast gives each game its own card in port A1 only. The cards in the other ports (A2 to D2) are shared by all games, like a real memory card. Restoring one as "this game's save" would wipe other games' data, so they never appear in LaunchBox's saves. The plugin's log mentions it when one of them holds data.
  • Machine files in the data folder (console memory, BIOS) are not game saves and are never listed.
  • A Dreamcast game has two names in Flycast: its memory card follows the disc's product number, its save states follow the game's file name. Renaming the game file means its old save states no longer match.
  • Arcade saves and states follow the zip's file name: keep MAME's set names.
  • Do not change Flycast's settings file while Flycast is open: Flycast rewrites it when it quits. The plugin refuses to write it while Flycast runs.
  • For the Options window to go over a game's own Flycast config, the plugin needs the game's Flycast id. It reads it from the disc, or asks a small helper tool placed next to flycast.exe. When neither works, it learns the id from Flycast's own log during that one launch.
  • Flycast's own fixes for known games always win over the Options window.
  • The RetroAchievements section of Flycast's settings cannot be set from the Advanced tab: the plugin manages it.
  • Only the Windows zip release of Flycast is installed; the Microsoft Store version is not.
  • The plugin's right-click entry and settings window are not shown in Big Box.
  • The game options are kept in the Flycast folder. If you delete or move that folder, they go with it.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\flycast.log (General tab: "Open the logs folder").
  • No download offered / "Couldn't determine which build of Flycast to install": GitHub may be limiting requests from your PC. Wait a few minutes and try again.
  • An arcade game does not start: check its BIOS is in Emulators\Nixx-Flycast\data (naomi.zip, naomi2.zip or awbios.zip), and that the game is still zipped.
  • A Naomi game says its disc image is missing: put the .chd named in the message into a folder named after the set, next to the zip.
  • A game will not launch and nothing happens: another Flycast game may still be running, or Flycast is open on its own. Close it and try again.
  • A game in the import list is missing: it may have been filtered out as not a Flycast game for that platform. Try with only Quick check, or look at the lines starting with [import] in the log.
  • Save state keys do nothing: if you had your own keyboard mapping in Flycast, the plugin left it as it was; bind save/load state in Flycast's Controls settings.
