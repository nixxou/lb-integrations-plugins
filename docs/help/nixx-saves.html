Nixx-Saves

What the pack does for the saves of games set to an emulator that is not one of its own.

In short

Nixx-Saves has no emulator of its own and nothing to set up. It comes with the pack and makes sure that a game's Game Saves shows every save any emulator keeps for that game - and that each one is backed up when the game quits and restored where its own emulator reads it - also on games whose emulator is not one of the pack's.

The pack's own emulators (ares, bsnes, melonDS...) already do this for their games; Nixx-Saves covers the rest.

Why it is needed

LaunchBox asks only the emulator a game is set to about that game's saves. A save made by another emulator - a game played once with Launch With, or moved from one emulator to another - is never shown, never backed up, and a restore would put it in the wrong emulator's folders.

Example: Final Fantasy VII is set to DuckStation, and you played it once with RetroArch. Without the pack, its RetroArch memory card is in no card at all; with it, it shows in Game Saves, is backed up when the game quits, and a restore writes it back into RetroArch's folder.

Games set to LaunchBox's own integrations

  • RetroArch, Dolphin, PCSX2: their own saves are shown as before, and the other emulators' saves of the game beside them. The cards of these three get an id in the pack's form (their original id is kept inside it, and they always see their own); the pack's setup gives them back their original form if you uninstall it.
  • DuckStation, MAME, RPCS3, Cemu, ScummVM, xemu, BigPEmu: LaunchBox gives them no save support at all. When another emulator with saves covers one of their platforms (RetroArch, ares...), their games get a Game Saves page with those emulators' saves. They have none of their own: a MAME arcade game no other emulator runs still has no Game Saves.

An emulator you added yourself

An emulator no plugin drives - one you added by hand, or one LaunchBox has no integration for - is taken by Nixx-Saves, so that its games show the other emulators' saves too. It changes nothing else:

  • the launch is exactly as you set it (its command line, its options);
  • its Edit Emulator screens show no version, no download and no update;
  • it is never offered when you add an emulator or import games.

Nixx-Saves never takes an emulator another plugin takes, nor one the pack or LaunchBox has an integration for (RetroArch, DuckStation, ares... even when you turned that integration off). Its log says which emulators it took and why.

Turning it off

Everything above is on the Compatibility page of Tools > Nixx Integration Plugins Configuration..., in the card Saves of every emulator (the advanced view has one line each):

LineWhat it covers
Every emulator's saves on games set to RetroArch, Dolphin or PCSX2The first list above.
Other emulators' saves on games set to DuckStation, MAME, RPCS3, Cemu, ScummVM, xemu or BigPEmuThe second list.
Other emulators' saves on games set to an emulator no plugin drivesAn emulator you added yourself.
RetroArch, Dolphin and PCSX2 save ids in the pack's formTurned off, their cards go back to LaunchBox's own ids at the next start.

Turned off, a game shows only its own emulator's saves, as in plain LaunchBox. Changes apply when LaunchBox (or BigBox) is restarted.

In LiteBox

LiteBox shows every emulator's saves of a game by itself: under LiteBox, Nixx-Saves steps aside and takes no emulator.

Limits and things to know

  • On a game set to an emulator you added yourself, a save changed during the session may not be backed up when the game quits. Use Backup Save on its card if you want a copy right away.
  • A card no emulator lists any more (its emulator removed, a save left from long ago) is deleted by LaunchBox itself when you choose Delete Save, after its own warning: the file goes for good.
  • To restore a save state, LaunchBox offers the slots of the game's emulator, even for another emulator's state; that emulator then takes the slot or says which one it needs.
  • Uninstall the pack only through its setup: it gives the RetroArch, Dolphin and PCSX2 cards back their original ids. The pack's own cards stay listed afterwards; restoring one of them through another emulator is not advised.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\nixx-saves.log (General tab: "Open the logs folder"). It lists the emulators taken or left at each start, and every save handed to another emulator.
