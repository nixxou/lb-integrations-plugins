In short

Demul emulates Sega's Dreamcast and the arcade boards built around it: Naomi, Naomi 2, Atomiswave, Hikaru and System SP, plus Cave's CV1000 and Gaelco's PowerVR board. It is the only emulator for Hikaru, and one of the very few for CV1000 and Gaelco.

The plugin installs the 2025 build of Demul, adds its platforms, and prepares Demul for each game: Demul cannot be handed a romset's path, so the plugin tells it where the game is and which system to start.

Getting started

  • Add Emulator > Nixx-Demul > Download. Demul goes into Emulators\Nixx-Demul.
  • The BIOS sets go, still zipped, into the roms folder beside demul.exe: dc.zip (Dreamcast - Demul has no built-in BIOS), naomi.zip, naomi2.zip, awbios.zip, hikaru.zip, segasp.zip. CV1000 and Gaelco need none.
  • Platforms. Sega Dreamcast, Sega Naomi, Sega Naomi 2, Sammy Atomiswave and Sega Hikaru are LaunchBox platforms. System SP, CV1000 and Gaelco are not: make a platform whose name holds System SP, CV1000 or Gaelco (scrape it as Arcade) and the plugin recognises it.
  • Arcade games stay zipped, under their MAME set name (mvsc2.zip, airtrix.zip...).

Playing a game

At each launch the plugin writes into Demul.ini the folder of the game and the roms folder of the BIOS sets - the folders you added yourself are kept - picks the video plugin the board needs, and starts Demul with -run=<system> -rom=<set> (or -run=dc -image=<disc> for the Dreamcast).

Saves and save states

Not handled by the plugin yet: Demul keeps the arcade games' saves in its nvram folder and the Dreamcast memory cards in memsaves.

Limits and things to know

  • CV1000 and Gaelco start in a window: press F3, then Alt+Enter.
  • A platform named "Gaelco" is taken for the PowerVR board (ATV Track, Smashing Drive, Gaelco Football). Gaelco's other 3D games - Speed Up, Surf Planet, Radikal Bikers - do not run in Demul.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\demul.log.
