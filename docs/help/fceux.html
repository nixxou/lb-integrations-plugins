In short

FCEUX is a Nintendo Entertainment System / Famicom emulator that also runs the Famicom Disk System. It tells a cartridge from a disk by the file itself, so one emulator covers every platform below.

The plugin downloads and updates FCEUX, adds it to LaunchBox for these platforms, puts each platform's saves, states and screenshots in their own folder of the emulator, finds the disk system's BIOS for you, starts games in full screen and binds the usual keys.

Archives (.zip, .7z, .rar, .gz) are opened by FCEUX itself.

Getting started

In LaunchBox: Tools > Manage > Emulators > Add, pick Nixx-FCEUX and press Download. FCEUX's latest release goes to Emulators\Nixx-FCEUX and the emulator is created with its platforms (the default only where you had none).

For the Famicom Disk System, the BIOS disksys.rom (8 192 bytes) must sit beside fceux64.exe. If you already have it in RetroArch's system folder or another emulator's BIOS folder (also as fds_bios.bin), the plugin copies it there itself.

Playing a game

Before FCEUX starts, the plugin writes into its fceux.cfg: the game's platform folders, the screen (full screen or window) and the keys below. FCEUX rewrites that file when it quits, so these settings come back at each launch.

KeyDoes
F2 / F4save / load a state in the current slot (FCEUX's own I / P still work)
F6 / F7previous / next slot
Escquit (the game's save is written)
Alt+Enterfull screen on and off

A key you already use for something else in FCEUX is never taken. FCEUX's own default "load slot 2 / 4 / 6 / 7" on F2 / F4 / F6 / F7 and "hide the menu" on Esc are given up for these.

Options

Tools > Nixx Integration Plugins Configuration..., the FCEUX page: the install, the disk system's BIOS, and the screen (full screen or windowed). Everything else is set in FCEUX itself.

Saves and save states

Nothing is written beside your games. Each platform has its own folder:

  • Emulators\Nixx-FCEUX\Saves\<platform> - the cartridge saves (.sav) and the disk saves (.fds)
  • ...\States, ...\Screenshots, ...\Cheats beside them

A save is named after the ROM - for an archive, the ROM inside it. What FCEUX had in its own sav, fcs, snaps and cheats folders is moved into the game's platform folder when the game is launched. If you set your own folders in FCEUX (Config > Directories), they are kept.

LaunchBox's Game Saves window does not list FCEUX's files yet.

Limits and things to know

  • FCEUX cannot open a file whose path has characters outside Windows' ANSI code page (Japanese names, for instance): such a launch is refused with a message. Rename the file with plain letters.
  • A disk game without disksys.rom is refused with a message saying where to put it.
  • An archive holding several ROMs makes FCEUX ask which one to play.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\fceux.log (General tab: "Open the logs folder").
