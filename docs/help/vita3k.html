In short

Vita3K is a PlayStation Vita emulator. The Nixx-Vita3K plugin lets you use it from LaunchBox like any other emulator: you keep your Vita games as files (.vpk, .zip or .pkg), you import them as ROMs, and you click Play.

The plugin works differently from a normal Vita setup. Nothing is installed in Vita3K for good. Each time you play, the plugin builds a fresh, clean Vita console, installs the game on it (with its update and DLC), restores your save, and starts the game. When you quit, it keeps only what the game changed - that is your save - and throws the console away. Your Vita stays clean, and each game's save is one file that LaunchBox's save manager can back up and restore.

On top of that, the plugin downloads Vita3K and the Vita system software (firmware) for you, fixes LaunchBox's import of Vita games, finds updates and DLC by itself, and gives each game its own settings window.

Getting started

1. Install Vita3K

  • In LaunchBox, add a new emulator and choose Nixx-Vita3K from the list, then let it download. The plugin fetches the latest Vita3K build and puts it in LaunchBox\Emulators\Nixx-Vita3K.
  • It then downloads the Vita firmware (about 300 MB) from Sony's own update servers and installs it. You do not need to look for it yourself. An internet connection is needed for this step.
  • Vita3K is set up to start games full screen, without its welcome window, and without checking for its own updates (updates come through LaunchBox, see below).
  • A notification then tells you which language, date and time format and confirm button (cross or circle) your games will use. These are taken from your Windows settings. Click Yes if they are right. Click No to open a small window and change them.
Keep your LaunchBox folder at a reasonably short path (for example D:\LaunchBox). The firmware contains very deep folders, and if the emulator folder path is too long (more than about 120 characters) the plugin refuses to install the firmware rather than leave you with a broken console. It checks this before downloading anything.

2. Import your games

  • Use LaunchBox's normal Import > ROM Files wizard. Pick your files, choose the platform Sony Playstation Vita and the emulator Nixx-Vita3K.
  • File types the plugin can play:
    • .vpk - the usual homebrew and game package;
    • .zip - for example a "NoNpDRM" game dump, which carries its own licence. A zip can also hold the game together with its update and DLC;
    • .pkg - a PlayStation Store package. A .pkg never contains its licence: you must supply it (see below).
  • Leave the files as they are. Do not unzip them: the plugin reads and installs them itself at each launch.

Why the import needs help. When you choose "Sony Playstation Vita", LaunchBox normally ignores the files you picked and lists games already installed inside Vita3K instead. With this plugin nothing stays installed, so that list would be empty. The plugin quietly works around this: the wizard scans your files like ordinary ROMs, and the games are still imported under "Sony Playstation Vita" with their metadata and images. This only happens in LaunchBox (not Big Box).

The game list is tidied before you click Finish. Each file is read, and:

  • games get their real title, taken from the game itself (for example "LittleBigPlanet PlayStation Vita"), without the ™ and ® signs;
  • updates and DLC are removed from the list (they are not separate games) and remembered, so the game finds them when you play;
  • a .pkg game whose licence cannot be found is removed, because it could not start anyway;
  • anything that is not a Vita game is removed.

You can still change the list before Finish. After the import, each game's Region is filled in from the game itself (North America, Europe, Japan, Asia, Korea), and its Version field keeps only the tags of the file name, like [PCSA00017] [USA] [NoNpDRM]. Each of these three helpers can be turned off (see Options).

3. Licences for .pkg files

The plugin ships no licences. For each .pkg game or DLC you own, give it the licence in one of these ways:

  • a licence file next to the .pkg with the same name: MyGame.rif, MyGame.bin, MyGame.work.bin, or a text file MyGame.zrif holding the licence text (a "zRIF"). A licence file with another name in the same folder is also found, as long as it belongs to that package;
  • or a table in the folder LaunchBox\Emulators\Nixx-Vita3K\zrif\. The plugin puts a ready-made my-licences.tsv there, with the explanation inside. Each line holds a Content ID (like UP0000-PCSE00000_00-XXXXXXXXXXXXXXXX) and its zRIF, separated by a tab. You can have several such tables.

A licence is only used for the exact package it was made for. An update in .pkg form needs no licence: it uses its game's.

4. Updates and DLC

You do not import updates and DLC as games. The plugin looks for them at each launch, around the game's file:

  • next to the game, in a file whose name contains the game's ID (like PCSA00017);
  • the same, inside a sub-folder named DLC, Update or Patch (or the same in the plural);
  • in any folder named after the game's ID, or after the game's title, below the game's folder;
  • inside the game's own zip;
  • and anywhere the import found them in the same batch of files.

Names only point the way: a file is used only if its contents say it really belongs to that game. By default the game gets every DLC and the highest update (Vita updates include all earlier ones). You can change this per game in the Options window.

Updating Vita3K: use the plugin's Download button in LaunchBox's emulator window when a newer build is offered. Your firmware, settings and saves are kept.

Playing a game

When you click Play, the plugin:

  • builds a fresh console from the clean firmware, in memory (a RAM disk) when your PC has enough free memory and the RAM disk is set up, otherwise in a folder on your disk;
  • installs the game, its update and DLC on it (decrypting the game if needed);
  • puts your save back;
  • applies the game's own settings, if you set any;
  • starts Vita3K directly on the game.

A small window shows the progress when this takes more than a moment. It also shows the game's state in Vita3K's compatibility list (for example "Playable" or "Ingame"), with a link to its report. Playing the same game again is fast: if the console still holds that game, nothing is rebuilt.

If a save may not suit the game as it is now - it was made with a newer update that is no longer found, or with a DLC that is gone - the plugin asks before loading it. If you answer No, the game starts without it and the save is kept aside as a copy.

Quitting

  • Press Esc, use the Exit of LaunchBox's or Big Box's pause screen, or close the window. Vita3K does not ask for confirmation.
  • Vita3K tends to go back to its own game list instead of quitting, or to hang while stopping. The plugin closes it for you about five seconds after the game window is gone.
  • A closing window then appears while your save is taken and the RAM disk is released. LaunchBox stays locked until it is done - this only takes a few seconds. Do not turn off the PC during it.

Options

The pack's window: Tools > "Nixx Integration Plugins Configuration..."

The Vita3K tab has:

  • Import Vita games as ROM files - the import fix described above (on by default);
  • Put the game list right before importing - titles from the games, updates and DLC taken out (on by default);
  • After the import, set each game's region and version;
  • System settings - the language, date format, time format and confirm button Vita3K tells every game. Vita3K must be closed to change them;
  • Open config.yml... - opens Vita3K's own settings file in Notepad, for everything else. Close Vita3K first: it rewrites that file when it quits.

Note that game titles in your library stay in US English whatever language you choose here.

Per game: right-click > "Nixx-Vita3K : Options..."

Right-click a game (or a selection of games) in LaunchBox. The entry is provided by the pack's menu plugin and appears for any game a Nixx-Vita3K can run. It is not available in Big Box. The window has several tabs:

  • Session - where the console lives while you play: RAM disk (default; falls back to the disk when memory is short), Disk only, or VHDX files (the game is installed once into virtual disk files kept in a folder you choose, so later launches skip the install). Also the RAM disk safety margin and how much memory to keep free for Vita3K itself. Left empty, that last one uses what the game needed last time plus 15%.
  • Updates & DLC - which update the game runs with (Automatic = the highest found, a specific one, or None) and which DLC to leave out. One game at a time. A DLC found later is added automatically. Changing this can affect existing saves, so the window warns you first.
  • System - a different language, date, time format or confirm button for this game only.
  • Graphics - Vita3K's renderer (Vulkan or OpenGL), image quality settings and FPS hack, for this game.
  • Compatibility - the game's state in Vita3K's compatibility list, and three settings some games need: File loading delay (for games that load too fast, such as Silent Hill), CPU optimizations and NGS audio (some games crash or have no sound with them).
  • Advanced - shows what the other tabs change, and lets you write Vita3K's per-game settings by hand. Preview result... shows exactly what Vita3K will read.

Every setting can stay on "default", which means the game runs as it would without the plugin. A coloured bar next to each setting shows where its value comes from, and Reset to defaults puts everything back. With several games selected, OK applies the window to all of them (you are asked first).

These per-game settings are applied only while the game runs; Vita3K's own per-game file is put back as it was when you quit. So a change you make in Vita3K's own game settings during such a session is lost - the window says so in red. Click Pause these settings to keep the plugin's settings for the game without using them: the game then runs on Vita3K's own settings, and changes made there are kept.

The Game settings in Vita3K... button at the bottom opens Vita3K on the selected game(s) without starting them, so you can use Vita3K's own "Custom Config" menu (right-click the game in Vita3K's list). The game cannot be played from there. Close Vita3K when you are done.

Saves and save states

  • Each game has one save file, which holds everything the game wrote during your sessions. LaunchBox's save management shows it with a VITA chip ("Vita save"), and you can back it up, restore it or delete it there.
  • A restored save is used at the next launch: the console is rebuilt around it.
  • The save stays valid when you change the update or DLC. Only two cases ask before loading: a save made with a higher update than the game now has, or with a DLC that is no longer there.
  • Saves live in LaunchBox\Emulators\Nixx-Vita3K\portable\saves\, one folder per game ID.
  • No save states. Vita3K has no save states at all, so the plugin adds no save/load state hotkeys. Use the game's own save system.

Limits and things to know

  • One game per file. If a zip holds several games, only the biggest is used.
  • The first launch of a game takes time. A large game has to be copied and decrypted (several seconds for a 4 GB game). The progress window tells you what is happening.
  • Memory. With the RAM disk, the whole console is in memory during play. If memory runs short, the plugin first frees idle memory from other programs, then uses the disk instead.
  • Do not cut the power during a game. A RAM disk does not survive a crash or power cut: the session you were playing would be lost (your previous save stays).
  • Do not install games in this Vita3K by hand. The console is rebuilt at every launch; whatever you install by starting Vita3K on its own is moved aside.
  • If you point the plugin at a Vita3K you already used before, it does not move that install's data around, so your old games and saves there stay where they were. The plugin works best with the Vita3K it installs itself.
  • Changing the update or DLC of a game may make old saves load wrong. The plugin keeps the save either way and asks when it sees a risk.
  • Licences are never included: you need your own for every .pkg.
  • Changes made in Vita3K's own game settings during a game that has plugin settings are not kept (see Options, "Pause these settings").
  • The import fix and the right-click Options are for LaunchBox; they do nothing in Big Box.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\vita3k.log (General tab: "Open the logs folder"). It says why a game was refused, which updates and DLC were found or set aside, and which licence was used or missing.
  • Vita3K's own log: LaunchBox\Emulators\Nixx-Vita3K\portable\vita3k.log, rewritten at each start.
  • A .pkg game does not start: its licence is missing or belongs to another package. Check the file name next to it, or the Content ID in your zRIF table.
  • A DLC or update is not used: open the game's Options, tab Updates & DLC, to see what was found. The log explains why a file was not kept.
  • The firmware will not install: check your internet connection, and that the LaunchBox folder path is not too long.
  • A game crashes or has no sound: look at its compatibility state, and try the Compatibility tab (CPU optimizations, NGS audio, file loading delay) or another renderer in Graphics.
  • The import shows no games: make sure "Import Vita games as ROM files" is ticked in the Vita3K tab of the pack's window.
