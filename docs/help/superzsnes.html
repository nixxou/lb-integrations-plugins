In short

SUPER ZSNES is a new Super Nintendo emulator by the authors of the original ZSNES. It is free to download from zsnes.com, but it is not open source. It is a different program from the old ZSNES. It plays one console: the Super Nintendo Entertainment System.

The Nixx plugin lets you install and update SUPER ZSNES from LaunchBox, play your SNES games with it, set options per game from a right-click, and see your cartridge saves and save states in LaunchBox's save management.

To do some of this, the plugin also puts a small helper inside the emulator, called BepInEx. It is a common free tool that lets the plugin adjust the emulator while it runs. It shows nothing on screen and writes no log by default. You can turn it off (see Limits).

Getting started

Installing the emulator

  • In LaunchBox, add a new emulator (Add Emulator) and pick Nixx-SuperZSNES in the list. Let LaunchBox download and install it.
  • The plugin downloads the latest Windows version from zsnes.com and installs it in LaunchBox\Emulators\Nixx-SuperZSNES.
  • It creates an emulator entry named Nixx-SuperZSNES, set as the default emulator for Super Nintendo Entertainment System.
  • The mouse cursor is left visible during games, because the emulator's menus are used with the mouse.
  • It also downloads and installs the in-game helper (BepInEx), unless you turned it off first.
The first start after installing takes about a minute before anything shows. The helper prepares itself once, silently. Later starts are normal.
The SUPER ZSNES site itself warns that some antivirus programs wrongly flag the emulator. If the install says the program file is missing, look in your antivirus quarantine, restore it (or exclude the folder) and install again.

Updating

  • LaunchBox's usual update check compares your version with the one on zsnes.com and offers the new one.
  • An update is unpacked over your existing folder. Nothing in the folder is deleted first.

Importing games

  • Import your SNES games as usual and choose Nixx-SuperZSNES as the emulator.
  • Supported files: .sfc, .smc, .swc and .zip. The emulator opens .zip files itself, so LaunchBox does not unpack them.

Playing a game

  • When you click Play, the plugin adds your chosen options for this game to the emulator's command line, then the game starts. No extra window appears.
  • Only one game at a time: a second launch while SUPER ZSNES is still open is refused. A quick double click starts the game only once.

Keys in the game (with the helper)

  • Esc no longer opens the menu at once. The first press shows "Press ESC again to quit". A second press within 2.5 seconds lets the emulator save, then quits. You can turn this off.
  • F1 opens the emulator's own menu (save states, cheats, its settings). You can choose another key.
  • F2 saves a state, F4 loads it, F3 changes the slot. These are the emulator's own keys.
  • A controller Exit button, if you set one in the emulator, still quits at once, without asking.

Pop-ups

The emulator's "support us on Patreon" and "a new version is out" dialogs are hidden by default. LaunchBox still checks for updates.

When you quit

  • The emulator saves its own settings as usual. The options you set per game are not kept in them (see Options).
  • If a game used window options (size, full screen, monitor), the window settings SUPER ZSNES remembers in Windows are put back as they were before the game, about a second after it closes. So one game's window settings do not carry over to the next game.

Options

There are two places. In both, each row has a small bar on the left: blue means it is passed to the emulator, grey means the emulator keeps its own setting (or the plugin's default). The bottom of the page shows what will be passed at launch.

For every game: Tools > Nixx Integration Plugins Configuration...

Open the SUPER ZSNES tab. These options apply to all games:

  • Install the in-process plugin (BepInEx): on by default. Off: the helper is not installed or repaired any more.
  • Escape asks before quitting: the double Esc described above. Off: Esc opens the menu, as the emulator ships.
  • Key that opens the emulator's menu: F1 by default.
  • Keep settings beside the emulator: the emulator's settings file is kept in a portable folder in the emulator's folder, instead of your Windows user profile.
  • Saves, states and cheats beside the emulator: see Saves.
  • Show the "support us on Patreon" dialog and Show the "a new version is out" dialog: both off by default.
  • Write the overrides into the emulator's settings file: off by default. See below.

Under the options, a box lists each SUPER ZSNES in your library with the helper's state and a button: Install now (for an emulator installed before the plugin, or by hand) or Repair / refresh.

For one game: right-click > Nixx-SuperZSNES : Options...

Right-click a SNES game (or select several) and choose Nixx-SuperZSNES : Options.... With several games, the same options are given to all of them after you confirm.

  • Window: always full screen on the main display, full screen or windowed, width and height, borderless window, which monitor.
  • Start-up: resume the last state when the game starts.
  • Display: screen effect (none, scanlines, 3D effect), scanline strength, smoothing, no bilinear filtering, maximum brightness, 8:7 picture instead of 4:3.
  • Gameplay: turn rewind off, rumble, right stick changes game speed, swap the accept and cancel buttons.
  • Audio: interface, game and MSU-1 volume.

Each option shows "SUPER ZSNES's own" (with its current value when the plugin can read it) until you change it. Leave it that way to keep the emulator's setting.

Options you set here are used only while the game runs. They are never saved into the emulator's own settings, so opening SUPER ZSNES on its own, or another game, is not affected. The only exception is the Write the overrides into the emulator's settings file option in the tab: when it is on, they are saved for good.

Most options need the helper. Without it, only the window options and "resume the last state" still work, except "always full screen on the main display", which needs the helper too.

Saves and save states

Where they go

  • With the option Saves, states and cheats beside the emulator (on by default), the emulator keeps them in its own folder: saves (cartridge saves), states (save states) and cheats, next to SUPERZSNES.exe.
  • This is written into the emulator's settings, so it also holds when you open SUPER ZSNES on its own.
  • It is only done when the emulator has no folder set. A folder you chose yourself in the emulator stays yours.
  • For a zipped game, the save is named after the zip file.
Old saves are not moved. If you played before with saves next to your games, the emulator no longer sees them. Move them yourself: the .srm file into saves, the game's .data.szsnes folder into states. Or turn the option off before your first launch.

In LaunchBox's save management

  • LaunchBox shows the cartridge save (marked SRM) and the save states (marked STATE, with their slot number).
  • You can back them up, restore them and delete them. A restore puts the file back where the emulator reads it, and asks before replacing one.
  • The plugin looks where the emulator's settings say, so it follows folders you changed in the emulator.
  • Not listed on purpose: the "last state" the emulator rewrites each time you open its menu or quit, and its rewind history.

Pause screen hotkeys

  • The plugin fills the emulator entry's AutoHotkey scripts, but only if they are empty: save state sends F2, load state sends F4, exit sends Alt+F4.
  • If you change those keys in the emulator, the scripts still send the old ones. Edit them in the emulator entry.

Limits and things to know

  • The in-game helper (BepInEx). It is put into the emulator's folder and runs inside the emulator to add the features above. To stop it being installed or repaired, untick Install the in-process plugin (BepInEx) in the SUPER ZSNES tab. To switch it off in an emulator where it is already installed, delete the file winhttp.dll next to SUPERZSNES.exe: the emulator is then exactly as it ships. Without the helper, most options do nothing.
  • Per-game options are never saved into the emulator's own settings, unless you turn on "Write the overrides into the emulator's settings file".
  • Saves, states and cheats go in the emulator's folder (saves, states, cheats). Older saves next to your games are not moved, and the emulator stops seeing them.
  • RetroAchievements are not supported. The plugin does not pass your LaunchBox login to the emulator. The emulator's own achievements feature is still marked "work in progress" by its authors.
  • Emulator updates. SUPER ZSNES is closed source. A new version of the emulator may stop one of the helper's features from working. The game still runs; only that feature is lost until the plugin is updated.
  • Only the Windows version of SUPER ZSNES is used.
  • If you typed an option yourself on the emulator's command line in LaunchBox, the plugin does not add the same one again: yours wins.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\superzsnes.log (General tab: "Open the logs folder").
  • The install says the emulator file is missing: your antivirus probably removed it. Restore it from quarantine and install again.
  • Options seem ignored: open the SUPER ZSNES tab and look at the helper box. If it is not installed, click Install now, or Repair / refresh. Antivirus programs sometimes remove winhttp.dll too.
  • A feature stopped working after an emulator update: look for portable\nixx-errors.log in the emulator's folder. It lists what the helper could not set up.
  • A game does not start because SUPER ZSNES is already open: close the emulator first, then click Play again.
  • Your old saves are gone: they are still next to your games. Move them into the emulator's saves and states folders.
