In short

Mesen is Sour's accurate multi-system emulator, carried on by the nesdev community as MesenCE. It runs the NES and Famicom (with the Famicom Disk System), the Super Nintendo (with Satellaview and Sufami Turbo games), the Game Boy, Game Boy Color and Super Game Boy, the Game Boy Advance, the PC Engine / TurboGrafx-16, SuperGrafx and PC Engine CD, the Master System, Game Gear, SG-1000, ColecoVision, and the WonderSwan, WonderSwan Color and Pocket Challenge V2.

The plugin installs and updates MesenCE from LaunchBox, sets it up for every one of those platforms, finds the BIOS files you already have, and keeps each platform's saves and save states in a folder of its own.

Getting started

  • In LaunchBox: Tools > Manage > Emulators > Add, pick Nixx-Mesen and press Download. MesenCE's latest release goes into Emulators\Nixx-Mesen.
  • Nothing else to install: Mesen is a native build - no .NET runtime, no Visual C++ package. Windows 10 or 11.
  • The emulator entry gets one row per platform. Where no emulator was the default for a platform yet, Mesen becomes it; an existing choice is left as it is.
  • Mesen is set up "portable": its settings, BIOS and saves all stay in its own folder.
  • A Mesen you installed yourself is used as it is (the plugin never updates it).

Playing a game

When you click Play, the plugin checks the console's BIOS when it needs one, binds the pack's keys in Mesen where they are free, points Mesen's save folders at the game's platform, and starts Mesen in full screen. When Mesen quits, the settings changed for that game only (its folders) are put back as they were in Mesen.

KeyIn Mesen
F2 / F4Save / load a state in the current slot
F6 / F7Previous / next slot
F11Full screen on and off (Mesen's own)
EscQuit (Mesen's own default for Esc, Pause, moves off it)

A key is bound only when Mesen's action has none and nothing of yours is on the key; Mesen's own defaults on those keys (load slot 2/4/6/7, Pause) are taken off them then. Shift+F1..F7 still save slots 1-7, F1..F7 load them where free.

Options

Tools > Nixx Integration Plugins Configuration..., Mesen page: the install, the BIOS found for each console, and full screen or windowed. Everything else - picture, sound, pads, each console's options - is Mesen's own: set it in Mesen's menus, the plugin leaves it alone.

A game of its own: right-click it, Nixx-Mesen : Options... (one game or a selection). There: the console Mesen runs it as (only where Mesen has a model to pick - Game Boy, Color or Super Game Boy; PC Engine, TurboGrafx or SuperGrafx; the WonderSwans), its screen, and a few of Mesen's own options for that game alone - filter, aspect ratio, region, sprite limit - each "As set in Mesen" until you choose. A choice is used for that game's session only: Mesen's own value comes back when it quits, and a filter or an aspect ratio is Mesen's override for that game's console, never another console's games.

No platform row carries a console model: Mesen picks the model from the game itself (Game Boy or Color, SuperGrafx, WonderSwan or Color), as set in Mesen. A switch you write on a platform row's line (Edit Emulator > Associated Platforms), --gameboy.model=GameboyColor say, is used as written.

Saves and save states

Mesen never writes beside your games. For a game launched from LaunchBox its files go to

  • Emulators\Nixx-Mesen\Saves\<platform>\ - the game's save (.sav, .srm, .rtc...)
  • ...\Saves\<platform>\States\ - its save states (<game>_1.mss ... _10.mss, and _11.mss the automatic state)
  • ...\Saves\<platform>\Screenshots\

What Mesen wrote in its own Saves and SaveStates folders for a game (opened by hand) is moved into the platform's folder at the game's next launch. A folder you chose in Mesen's own settings is kept.

LaunchBox's Game Saves window lists the game's save - with its clock (.rtc) or other battery files, kept together - and its save states, each with the picture Mesen stores inside the state. A state can be restored into another slot; a save is restored only while Mesen is closed (it writes the game's own when it quits).

Limits and things to know

  • A PC Engine CD game must be its .cue (with its tracks): Mesen opens no .chd and no .m3u.
  • An archive holding several games: the one named after the archive is played; otherwise keep one game per archive.
  • Mesen has no RetroAchievements.
  • Mesen runs one window at a time: a game launched while Mesen is open goes to that window, with the save folders of the game already there - close Mesen first.
  • Pocket Challenge V2 needs MesenCE (2.2 or later).

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\mesen.log (General tab: "Open the logs folder").
  • A game refused for its BIOS: the message names the file and the folder; put the file there under that name.
  • Mesen shows its setup wizard: its settings.json is missing; launching any game from LaunchBox writes a first one.
