In short

Kronos is a Sega Saturn emulator of the Yabause family, started by FCare and carried on today by Benjamin Siskoo, whose site Tradu-France publishes its Windows builds. It runs fast and can draw the games above their original resolution. The plugin installs and updates Tradu-France's 64-bit build, finds your Saturn BIOS, starts each game with its own backup RAM and its own save states, and gives it the pack's keys - a key for the next disc too.

Getting started

  • Install: Tools > Manage > Emulators > Add, choose Nixx-Kronos, Download. Kronos goes to Emulators\Nixx-Kronos, portable: its kronos.ini, BIOS, saves and states stay in that folder. It needs the Microsoft Visual C++ runtime (x64): its installer, vc_redist.x64.exe, comes with it.
  • BIOS: the plugin keeps the Saturn BIOS in Emulators\Nixx-Kronos\bios. It looks in RetroArch's system folder and the other emulators' bios folders (Ymir's too), recognises a BIOS by its content - the name does not matter - and copies it. At each launch Kronos is given the one of the disc's region: mpr-17933.bin for American and European discs, sega_101.bin for Japanese ones.
  • Games: .chd, .cue (with its .bin), .ccd (with its .img), .mds, .iso, a .m3u for several discs, or a .zip / .7z holding them - platform Sega Saturn.

Playing a game

  • The game starts by itself, in full screen (a choice in the Nixx window and in each game's window).
  • A .m3u starts on its first disc; an archive is unpacked once into Emulators\Nixx-Kronos\Unpacked.
  • The game gets its own backup RAM (the Saturn's memory where games save, 32 KB as on the console): Saves\Sega Saturn\<game>.bkr in Kronos's folder, named after the .m3u or the disc without "(Disc N)" - the discs of a game share it - and its own folder of save states, Saves\Sega Saturn\States\<game>. Kronos's own settings are put back when it quits.
  • Quit with Esc or LaunchBox's Exit: Kronos closes cleanly.

Kronos has no "current slot", and its own Ctrl / Alt + digit keys do nothing: the plugin sets each slot's save on Ctrl+Shift+F1...F10 and its load on Shift+F1...F10 in kronos.ini, and the AutoHotkey script of the emulator entry, active in Kronos's window only, sends them for the slot it counts. Kronos's own settings window: Ctrl+S (in a window, not in full screen).

Options

  • Nixx window (Tools > Nixx Integration Plugins Configuration..., page Kronos): the screen every game gets, the install, the BIOS found.
  • Right-click a game > Nixx-Kronos : Options...: its discs (title, product code, area), its save with RetroArch, its own screen.
  • Everything else is Kronos's own: its Settings window.

Saves and save states

  • LaunchBox's save management sees each game's backup RAM and its save states (slots 1-10), with backups and restore. A state is named by its disc's product code; it goes back to that disc of the game. Restoring needs Kronos closed.
  • The backup cartridge: a game that has one (Saves\Sega Saturn\<game>.bcr, 4 Mbit) gets it plugged in Kronos for its session, and listed in LaunchBox beside its backup RAM. A game without one plays with what Kronos's settings say.
  • With RetroArch and Ymir: the backup RAM and the cartridge are the same files as RetroArch's Beetle Saturn (.bkr, .bcr) and Ymir's - no conversion. Right-click the game > Nixx-Kronos : Options... > Its save, with RetroArch: import or export. What is replaced is kept, dated, in Saves\Sega Saturn\replaced. Save states cannot be carried: each emulator reads only its own.

Limits and things to know

  • A game played in Kronos before the plugin kept its saves in Kronos's own bkram.bin (in %AppData%\kronos), not in the game's file.
  • Kronos's states may not load in another version of Kronos.
  • If you rebind Kronos's slot keys or its Eject/Load ISO (Ctrl+I), F2 / F4 and the next-disc key send the old ones.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\kronos.log (General tab: "Open the logs folder").
  • "Kronos needs a Sega Saturn BIOS": put one in Emulators\Nixx-Kronos\bios or RetroArch's system folder.
  • "Kronos is already running": close the Kronos already open - two would share one folder of saves.
  • Kronos does not start at all: install vc_redist.x64.exe from its folder.
