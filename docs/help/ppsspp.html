In short

PPSSPP is the reference emulator for the Sony PSP. The Nixx plugin, listed in LaunchBox as Nixx-PPSSPP, installs it for you, keeps it up to date, and connects it to LaunchBox.

On top of plain LaunchBox it adds:

  • a one-click install and update from PPSSPP's official releases;
  • ready-to-use keys for save states (F2 to save, F4 to load) and a clean Escape to quit;
  • your RetroAchievements login, passed to PPSSPP before each game;
  • your PSP saves and save states, listed in LaunchBox's save management, with backup and restore;
  • a right-click window with the game's state in PPSSPP's compatibility reports, and its updates to install.

PPSSPP needs no BIOS or firmware. Nothing to find or copy.

Getting started

Install PPSSPP

  • In LaunchBox, open Tools > Manage > Emulators, click Add, and pick Nixx-PPSSPP in the list. Let LaunchBox download and install it.
  • The plugin downloads the latest Windows 64-bit release from PPSSPP's official GitHub page (the ARM64 build only if a release has no 64-bit one).
  • It goes into Emulators\Nixx-PPSSPP inside your LaunchBox folder. The name is prefixed on purpose, so it never collides with LaunchBox's own PPSSPP folder.
  • The emulator entry is created for you, set as the default emulator for Sony PSP, with the command line --fullscreen --pause-menu-exit.

Where your data lives

This install is portable: saves, save states and settings are all kept in Emulators\Nixx-PPSSPP\memstick, next to the emulator. Back up that folder and you have everything.

You already have PPSSPP set up yourself? An emulator entry that points to a PPSSPP program (PPSSPP...exe) is recognised too. If it was installed with PPSSPP's own installer, its data is in Documents\PPSSPP, and the plugin reads it from there. It never moves your data.

Updates

When a newer PPSSPP release is out, LaunchBox shows an update for the emulator. The update unpacks over the existing folder: your memory stick (saves, states, settings) is kept. If the installed version cannot be read, no update is offered rather than one forever.

Import your games

Import your PSP games into the Sony PSP platform as usual. Accepted files: .iso, .cso, .zso, .chd, .pbp, .elf, .prx, .zip, .ppdmp. Files are not extracted by LaunchBox: PPSSPP opens them directly.

While the list of the import wizard is on show, the plugin reads each game's own description (its PARAM.SFO) and puts the list right:

  • A game update is taken out of the list: it is not a game. It is noted for its game and offered in that game's Updates window (right-click). Nothing is installed unless you ask.
  • A firmware update ("PSP Update ver ...") is taken out: PPSSPP needs no firmware.
  • The name: the file's name is kept when LaunchBox's database knows it, else the game's own title when the database knows that (written as the database writes it), else the file's name, unless it is only a serial like ULUS10041.
  • The region comes from the game's serial: ULUS / NPUH North America, ULES / NPEH Europe, ULJM / NPJH Japan, and Asia and Korea.
  • A .zip is read too: the .iso or .pbp in it, decompressed only as far as its description, so the first time takes a moment. A .cso or .chd inside a zip, an .elf or a .prx cannot be read: it stays in the list as it is.
  • What was read is remembered, even when you move the file to another folder: importing the same games again is instant.

The three parts (filter, name, region) can each be turned off in the PPSSPP tab of Tools > Nixx Integration Plugins Configuration.

Game updates: right-click the game, Nixx-PPSSPP : Compatibility & updates..., pick an update and click Install the selected. It goes into PPSSPP's memory stick (PSP\GAME\<its id>\PBOOT.PBP), where PPSSPP starts it instead of the disc, when it is made for your disc's version (one for another version is shown in amber). Remove the installed one takes it out again; one you put there yourself is never touched.

For the best results use .iso, .cso, .zso, .chd or .pbp (or an .iso / .pbp in a .zip, once it has been imported or launched). The plugin can read the game's ID from these, which is what links a game to its saves, its save states and its own options.

Playing a game

When you click Play, just before PPSSPP starts, the plugin:

  • passes your RetroAchievements account from LaunchBox to PPSSPP (hardcore follows the emulator's setting in LaunchBox). If this fails, the game starts anyway;
  • makes sure the save state keys are in place (see below);

PPSSPP opens full screen.

Keys

KeyWhat it does
F1PPSSPP's pause menu
F2Save state in the current slot
F4Load state from the current slot
F6 / F7Previous / next state slot
EscQuit PPSSPP and go back to LaunchBox
  • PPSSPP normally opens its menu with Escape and has no save state key. The plugin moves the menu to F1 and gives Escape to "quit", so LaunchBox's Exit works.
  • Only missing keys are added. A key you already use for something else is never taken, and a binding you changed yourself is left alone. Your controller buttons are never touched.
  • When quitting, PPSSPP itself may ask you to confirm (for example after a few minutes of unsaved play). That is PPSSPP protecting your progress.
  • LaunchBox's and Big Box's pause screen can save and load states too: the plugin fills in the emulator's save/load state scripts with these keys.

When you quit

Nothing to put back: the plugin does not change PPSSPP's settings for a game.

One game at a time

  • While a PPSSPP game is running, another launch from LaunchBox is refused. A quick double click is ignored silently; later, a message tells you the game is still running.
  • If PPSSPP is already open on its own, the launch is refused with a message: close it first, then launch the game again.

Options

Tools menu

Tools > Nixx Integration Plugins Configuration... opens the pack's window. The PPSSPP tab holds the import options. The General tab has a button to open this guide and an Open the logs folder button.

A game's own settings: in PPSSPP

PPSSPP keeps settings of its own for each game: in PPSSPP, right-click the game (or open its menu while it runs) and choose Game settings / Create game config. Everything you change there applies to that game only, every time it runs.

Right-click on a game: "Nixx-PPSSPP : Compatibility & updates..."

One game at a time. Under its title, its state in PPSSPP's compatibility reports - Perfect, Playable, Ingame, Menu/Intro or Doesn't Boot, the best rating any player's report gave it, as the site shows it - and a link to its report page, always. The plugin keeps the whole list (read again when PPSSPP is installed or updated) and reads the game's own page again when it is a week old. Below, the updates found for the game and the one installed, with Install the selected and Remove the installed one - see Updates above.

Saves and save states

Open a game's saves in LaunchBox (its save management page). For each PSP game you see:

  • Memory Stick: the game's save. A PSP game often writes several save folders (the save, its options, its system data); they are kept together as one save, named after the save's own title.
  • Save State: one entry per occupied slot, numbered 1 to 5 as in PPSSPP.

What you can do

  • Back up: copies all of the game's save folders, or the state file, to LaunchBox's save vault.
  • Restore: puts a backup back. For a save, the game's current save folders are replaced (LaunchBox asks before overwriting), so no old leftover stays mixed in. For a state, its screenshot comes back too when the backup kept it.
  • Delete: removes all of the game's save folders. For a state, it removes the slot, its screenshot and PPSSPP's "undo" copy of that slot.
  • Saves are found by the game's ID, read from inside the game file. Renaming a file does not lose its saves. When the ID cannot be read, the save is matched on the exact game title instead.
  • Folders that hold installed game data (not saves) are left out.
  • The backup history follows the game even if your memory stick moves, or a save folder is renamed. A state keeps its history when you update the game to a new version.
  • Keys: F2 save state, F4 load state, F6/F7 change slot, also usable from LaunchBox's pause screen.

Limits and things to know

  • First launch of a fresh install: PPSSPP writes its key file only when it quits for the first time. So the very first session uses PPSSPP's defaults (Escape opens the menu, no save state key). From the second launch on, the plugin's keys are there.
  • Game ID needed: the game ID can only be read from .iso, .cso, .zso, .chd and .pbp, and from the .iso or .pbp in a .zip once that zip has been imported or launched. For other files (a homebrew .elf, a .cso in a zip), save states are not listed, saves are found only by exact title, and its updates cannot be found.
  • Five state slots: LaunchBox only sees slots 1 to 5, PPSSPP's default, even if you raised the number of slots in PPSSPP.
  • State restore and game version: PPSSPP names a state after the exact version of the game. If a backup does not say which version it is for, and the game has no other state to learn it from, the restore is refused with a message. Save one state in PPSSPP, then restore again.
  • Settings files are not changed while PPSSPP runs: PPSSPP rewrites its settings when it quits, so the plugin waits. A game config left over by a crash is put back at the next launch, a few seconds after LaunchBox starts, or when you open PPSSPP on its own.
  • The update keeps old files: it unpacks over the folder to protect your saves, so files dropped by a newer release stay behind. This is harmless.
  • Escape and the exit question: PPSSPP may ask "are you sure?" when you quit. This is PPSSPP's own behaviour.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\ppsspp.log (General tab: "Open the logs folder").
  • For more detail in the log, create an empty file named trace (no extension) in that same folder, then restart LaunchBox.
  • F2 / F4 do nothing: launch the game once more after PPSSPP has run and quit at least once. If you had already put other actions on those keys, the plugin left them alone: check PPSSPP's control settings.
  • A game's update does not start: its Updates window shows it in amber when it is made for another version of the disc - PPSSPP only starts an update made for your disc's version.
  • The game will not launch: a PPSSPP window may still be open, or a previous game still running. Close PPSSPP and try again.
  • No saves listed: the game must have saved at least once in PPSSPP, and the save must be on the memory stick of the emulator the game uses.
  • Install fails: GitHub may be limiting downloads from your machine for a while. Wait a few minutes and try again.
