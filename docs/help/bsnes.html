In short

bsnes is the accurate Super Nintendo emulator Near wrote. Its last numbered release is v115 (2020); the community keeps it going and publishes a nightly build, which is what the plugin installs and updates.

The plugin installs it, writes the picture you chose before every game, starts it full screen, and shows its saves and save states in LaunchBox's save management.

Getting started

  • In LaunchBox, Tools > Manage > Emulators > Add, pick Nixx-bsnes and Download: the latest nightly is installed into Emulators\Nixx-bsnes, set as the Super Nintendo emulator.
  • A newer nightly: the same window's Download button offers it. Your settings.bml (pads, hotkeys, folders) is kept.

Playing a game

bsnes opens .sfc, .smc, .zip and .7z itself. Before the game starts the plugin writes your picture options into settings.bml and adds --fullscreen when you want full screen. Quitting from the pause screen closes the window, as its own close button does: bsnes writes the game's save then.

Options

Tools > Nixx Integration Plugins Configuration..., page bsnes, sets every game's; right-click a game, Nixx-bsnes : Options..., sets one game's own.

These settings are the plugin's: change them in bsnes's menus and they come back at the next launch. Everything else - pads, hotkeys, sound, folders - is yours, set in bsnes.

Saves and save states

  • Cartridge save: <game>.srm (and .rtc, .psr when the cart has them), in bsnes's saves folder: Emulators\Nixx-bsnes\Saves\ unless you chose another one. Nothing is written beside the games: states go to States\, cheats to Cheats\, screenshots to Screenshots\ of the same install.
  • A save or state an older bsnes left beside a game is brought into those folders at that game's launch (a .srm is copied, so another emulator that reads it there keeps it).
  • Save states: bsnes keeps every state of a game in one file, <game>.bsz. LaunchBox's save management backs it up and restores it as one.
  • Beside it, <game>.bsz.png is a thumbnail of the newest state, taken from the picture bsnes keeps in it. It is made after you quit bsnes, and travels with the state in backups.
  • bsnes ships no hotkey. When one is empty, the plugin binds the pack's: F2 save state, F4 load, F6 / F7 slot down / up, F11 full screen, Esc quit. A key you set is kept. LaunchBox's pause screen uses F2 / F4.

The other emulators' saves

  • A game's Game Saves also shows the saves the other emulators keep for it - one played with Launch With, or before the game moved to bsnes: RetroArch's, Dolphin's, PCSX2's and the other Nixx plugins'. Each card names its emulator.
  • They are backed up with bsnes's when the game quits, and a restore puts each one back where its own emulator reads it, never into bsnes's folders.
  • Two installs of one emulator (two folders) keep their cards apart; when a restore cannot tell which install a card is for, it asks you.
  • Turned off on the Compatibility page of the Nixx window (Saves of every emulator), a game shows only bsnes's saves, as in LaunchBox. The Nixx-Saves guide tells the same for games set to LaunchBox's own integrations.

Limits and things to know

  • A nightly is the project's latest build: newer, and tested less than a release.
  • A save restored while bsnes runs would be overwritten when it quits: close it first.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\bsnes.log (General tab: "Open the logs folder").
