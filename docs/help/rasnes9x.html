In short

RASnes9x is RetroAchievements' own version of Snes9x, the Super Nintendo emulator: Snes9x 1.63 with achievements, leaderboards and hardcore mode built in. It is the standalone Super Nintendo emulator RetroAchievements supports.

The plugin installs it, logs it in to RetroAchievements with LaunchBox's account, writes the picture you chose before every game, and shows its saves and save states in LaunchBox's save management.

Getting started

  • In LaunchBox, Tools > Manage > Emulators > Add, pick Nixx-RASnes9x and Download: RASnes9x 1.2 is installed into Emulators\Nixx-RASnes9x, set as the Super Nintendo emulator.
  • RetroAchievements' own library (RA_Integration.dll) is downloaded with it, and brought up to date before each game - exactly as RASnes9x would ask to. Without network, RASnes9x asks itself when it starts.

Playing a game

Before the game starts, the plugin writes your picture options into Snes9x's snes9x.conf and your RetroAchievements login into the toolset's file. Snes9x opens .sfc, .smc, .zip and the other ROM types itself; a .7z is unpacked by the plugin first, under the archive's own name.

Quitting from the pause screen closes the window, as its own close button does: Snes9x writes the game's save then.

RetroAchievements

  • Log in once in LaunchBox (Tools > Options > RetroAchievements): the plugin hands that login to RASnes9x at each launch. Logging in inside RASnes9x's own menu works too.
  • Hardcore follows the switch on the emulator in LaunchBox. In hardcore, RetroAchievements forbids loading a save state: RASnes9x asks whether to leave hardcore first.

Options

Tools > Nixx Integration Plugins Configuration..., page RASnes9x, sets every game's picture; right-click a game, Nixx-RASnes9x : Options..., sets one game's own.

These keys are the plugin's: change them in Snes9x's menus and they come back at the next launch. Everything else - pads, hotkeys, sound, folders - is yours, set in Snes9x.

Saves and save states

  • Cartridge save: <game>.srm (and .rtc for the few carts with a clock), in Snes9x's saves folder - Saves\ beside the emulator unless you changed it.
  • Save states: <game>.000 to .009, the ten slots: Shift+F1..F10 save, F1..F10 load. LaunchBox's pause screen saves and loads slot 0.
  • LaunchBox's save management lists both, backs them up and restores them.

Limits and things to know

  • RASnes9x is Snes9x 1.63, the last release; the newer fixes of Snes9x's nightly builds are not in it.
  • A save restored while RASnes9x is running would be overwritten when it quits: close it first.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\rasnes9x.log (General tab: "Open the logs folder").
  • Snes9x's own output: stdout.txt beside RASnes9x.exe.
