In short

3dSen PC, by Geod Studio, plays NES games as 3D dioramas. It does not turn just any ROM into 3D: it has a 3D profile for each game it knows (about a hundred built in, more from the community), and plays a game in 3D through its profile.

The plugin lets LaunchBox start a NES game straight into 3dSen: it finds the game's profile, tells 3dSen which ROM file to use for it, and starts 3dSen on that profile, full screen or in a window.

Getting started

3dSen is sold on Steam: the plugin never downloads it. In LaunchBox, Tools > Manage Emulators > Add, choose Nixx-3DSen and click Download. A window asks which 3dSen to use:

  • Use the Steam install - when Steam has 3dSen installed on this computer;
  • Install it with Steam - Steam is asked to install it; when Steam has finished, click Download again;
  • Choose the folder... - the folder of a copy you have, the one holding 3dSen.exe.

The emulator is set up for the platform Nintendo Entertainment System (and LiteBox's Nes - Super Mario Bros. Hacks).

Playing a game

When you click Play, the plugin looks for the game's 3D profile by its title (3dSen spells some titles its own way: the plugin knows those). It writes the game's file into 3dSen's list of games, then starts 3dSen on that profile: the game begins at once, in 3D.

If no profile matches, the game is not started and a message says so: right-click the game, Nixx-3DSen : Options..., and choose its profile there - or 2D Mode, which plays any game flat.

3dSen does not check that the ROM is the right game: a wrong profile plays the game with another game's 3D.

3dSen must not be running when you start a game: it rewrites its list of games when it quits.

Options

  • Tools > Nixx Integration Plugins Configuration..., page 3dSen: the 3dSen in use and its version, where it keeps its files, and the screen every game gets (full screen at the monitor's resolution, a window of a size, or as 3dSen last had it).
  • Right-click a game > Nixx-3DSen : Options...: the game's 3D profile and its own screen. The bottom shows the command line 3dSen will be given.
  • 3dSen's own settings (speed, shadows, the sky, the TV mode, the pads) stay in 3dSen's menu.

Saves and save states

F2 quick saves, F4 quick loads (bound by the plugin when 3dSen had no key for them). Esc opens 3dSen's menu, with its 36 save slots.

3dSen has no cartridge saves: a game that saves its progress on the cartridge (Zelda II, Final Fantasy, Dragon Warrior...) forgets it when 3dSen quits. Keep your progress with save states.

3dSen keeps its states in its own folder, %USERPROFILE%\AppData\LocalLow\Geod Studio\3dSen, shared by every copy of 3dSen. Their listing in LaunchBox's Game Saves is not there yet.

Limits and things to know

  • F6 / F7 / F11 do nothing special here: 3dSen uses F5-F8 to turn the camera, F9 / F10 to zoom, F3 to export the scene.
  • A game with no profile is refused rather than played with a guess.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\3dsen.log (General tab: "Open the logs folder").
  • 3dSen's own log: Player.log in its folder of files (above) - "Load profile ..." names the game it started.
