In short

puNES is an accurate Nintendo Entertainment System emulator by Fabio Cavallo (FHorse). It runs NES and Famicom cartridges - Vs. System dumps in the NES 2.0 format too - and Famicom Disk System disks.

The plugin installs puNES 0.111, sets it up for the NES, the Famicom Disk System and LiteBox's NES platforms, starts each game full screen with the options you chose for it, finds the Famicom Disk System BIOS for you, and refuses a game puNES could not start rather than showing an empty screen.

Getting started

  • In LaunchBox, Tools > Manage > Emulators > Add, pick Nixx-puNES and Download: puNES 0.111 (64-bit, Direct3D 9) is installed into Emulators\Nixx-puNES, for the platforms Nintendo Entertainment System, Nintendo Famicom Disk System, Nes - Super Mario Bros. Hacks and Nintendo Famicom. It becomes a platform's default emulator only where none is set yet.
  • puNES is set up portable: its settings, keys and saves stay in its own folder, and its first-run wizard never shows.
  • For Famicom Disk System games, puNES needs disksys.rom. The plugin copies it into Emulators\Nixx-puNES\bios from RetroArch's system folder or another emulator's BIOS folder when you have it there; otherwise put it there yourself.

Playing a game

puNES opens .nes, .unf, .fds and .qd files, and picks the system from the file itself. An archive (.zip, .7z) holding one game named after it is given to puNES as it is; any other archive (.rar too) is unpacked by the plugin into Emulators\Nixx-puNES\Unpacked under the archive's name, so a game's saves are always named after it.

Quitting from the pause screen closes the window, as its own close button does: puNES writes the game's save then.

One puNES at a time: a game launched while puNES is already open is refused - puNES would hand the game to the open window and quit at once.

Options

Tools > Nixx Integration Plugins Configuration..., page puNES: the screen every game starts on (full screen, windowed, or as set in puNES), and the Famicom Disk System BIOS. Right-click a game, Nixx-puNES : Options...: that game's own options - for several games at once too.

OptionChoices

EmulationPause in the background, save the cartridge every 3 minutes, rewind length
Every option of a game starts as As set in puNES: nothing is changed, puNES's own settings are used. A value chosen for a game is given to puNES on its command line when the game starts, and puNES does not keep it: its own settings come back when it quits. The bottom of the window shows that command line.

Saves and save states

  • puNES keeps them in its own folders, never beside the games: cartridge saves in prb\ (<game>.prb), save states in save\ (<game>.p00 to .p0B, 12 slots), Famicom Disk System disk changes in diff\, screenshots in screenshot\ - all in Emulators\Nixx-puNES. puNES has no setting to move them.
  • Keys: F1 saves the state of the current slot, F4 loads it, F2 / F3 change the slot, Alt+Enter full screen, Alt+Q quits - puNES's own keys. The pack's usual keys (F2, F4, F6, F7, F11, Esc) are bound only where puNES has nothing on them, and puNES's defaults use them all. LaunchBox's pause screen sends F1 / F4.
  • LaunchBox's save management for puNES comes with a later version of the plugin.

Limits and things to know

  • A game whose path holds an = sign cannot be opened by puNES (it cuts its command line there): the plugin says so and does not start it. Rename the file or its folder.
  • PlayChoice-10 dumps run as plain NES games: puNES does not emulate the PlayChoice hardware. MAME's Vs. System sets are not puNES's: they belong to MAME.
  • No newer puNES build can be downloaded today: the project's development builds have expired. A newer release comes with an update of the plugin.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\punes.log (General tab: "Open the logs folder").
  • A disk game shows nothing: disksys.rom is missing or is not the Famicom Disk System BIOS (puNES does not check it).
