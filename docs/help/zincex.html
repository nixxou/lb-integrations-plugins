In short

ZiNc runs the arcade games of Sony's ZN-1 and ZN-2 boards - PlayStation hardware in a cabinet: Capcom (Street Fighter EX, Rival Schools, Strider 2...), Taito FX-1 (Raystorm, G-Darius, Psychic Force), Raizing, Tecmo, Atlus, Konami GV and Namco System 11 / 12 (Tekken, Tekken 2, Tekken 3, Soul Edge...). 71 games in all. ZiNc EX is its modern launcher: a Direct3D 11 renderer, remappable pad controls, bezels, per-game settings.

The plugin installs ZiNc EX (it comes with ZiNc 1.1), and makes each game start from LaunchBox, whatever its romset is called.

Getting started

  • Add Emulator > Nixx-ZiNc-EX > Download. ZiNc EX goes into Emulators\Nixx-ZiNc-EX, with an Arcade platform that is not the default: MAME stays the platform's emulator.
  • Assign it to the ZN games (Edit > Emulation, or several games at once with Bulk Edit). The romsets stay zipped, where they are.
  • The BIOS sets - cpzn1, cpzn2, taitofx1, psarc95, tps, atluspsx, konamigv, or as a recent MAME names them coh1000c, coh3002c, coh1000t, coh1002e, coh1002m, coh1001l - go beside the games, or once in the roms folder beside ZiNc-EX.exe. A MAME non-merged set already carries its own. Namco's games need none.

Playing a game

ZiNc's sets are those of MAME 0.87 (2004). Since then MAME renamed most of them, and gave some names to other versions: MAME's sfex.zip is the European Street Fighter EX, which ZiNc does not know, while ZiNc's sfex is MAME's sfexu.zip. So the plugin tells which of ZiNc's games a romset is by the ROMs it holds - as ZiNc itself finds them, by their checksums - not by its name.

Then it gives ZiNc EX the game's zips under ZiNc's names (the game, its parent, its BIOS) in lbip-roms beside it - links to your files, nothing is copied when they are on the same drive, nothing is written beside your games - and starts ZiNc-EX.exe --game <set>. A folder of classic ZiNc romsets is given as it is. ZiNc EX's own ROMs folder is set for the launch and put back afterwards.

Measured on a MAME 0.288 non-merged set: 64 of the 71 games are found. The other 7 - Tekken 2's three versions, Dunk Mania's two, Psychic Force EX and Bloody Roar 2 - hold other dumps today than ZiNc's, and cannot start in ZiNc 1.1 from that set.

When the file you imported is another version and the right one sits beside it (MAME's tekken3.zip is not ZiNc's, its tekken3je1.zip is), the message says which file to give the game.

Options

Picture, resolution, sound, controls and bezels are ZiNc EX's own: set them in ZiNc EX's window, for every game or per game (Game > Game Settings). The launch from LaunchBox takes them as they are.

In Tools > Nixx Integration Plugins Configuration, page ZiNc EX: the install, where the parent and BIOS zips are looked for, which BIOS sets are found, and how the game's window opens - full screen (the default), windowed, or as set in ZiNc EX.

Right-click a game, Nixx-ZiNc-EX : Options...: which of ZiNc's games its romset was found to be and what ZiNc EX is given - or why it cannot start - the ZiNc game to start it as when you want another one (a merged set holds several), and its own window option. Several games selected: the option goes to each.

Saves

Not handled by the plugin yet: ZiNc keeps the games' settings and high scores in the cfg folder beside it, and has no save states. Its files are looked at before the plugin backs them up.

Keys

KeyDoes
EscQuit - ZiNc's own key. LaunchBox's and Big Box's Exit do the same.

Coin, Start and the buttons are set in ZiNc EX, page Controls (keyboard and pads).

No save state keys: ZiNc has none. Your own scripts on the emulator entry are kept.

If something goes wrong

  • A game that cannot start says why before anything opens: which ROMs are missing, where the parent and the BIOS were looked for. When ZiNc EX itself refuses it, its reason is shown too (from its ZiNc-EX_launch.log).
  • Psychic Force may start in its test menu the first time: choose Factory Defaults, Yes, Exit, wait for RESET, quit and start it again (ZiNc's readme).
  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\zincex.log.
