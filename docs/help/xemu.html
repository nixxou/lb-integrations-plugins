In short

xemu plays games of the first Xbox. This plugin installs it and keeps it up to date. It also opens discs xemu cannot open on its own, and gives every game its own console, so your saves stay with the game.

Getting started

  • In LaunchBox, go to Add Emulator, pick Nixx-Xemu and click Download. It goes into Emulators\Nixx-Xemu.
  • xemu needs two files from a real Xbox, and the plugin can not give them to you: mcpx_1.0.bin (the boot ROM, 512 bytes) and a flash BIOS (a modified one, like Complex_4627.bin). Put them in Emulators\Nixx-Xemu\bios. If you already have them for the other Xemu plugin or in RetroArch's system folder, the plugin copies them for you at install.
  • The plugin also downloads the Xbox dashboard made by the xemu team. That is the base of every console.

Playing a game

  • An XISO starts as it is.
  • A redump ISO, a CSO, a CCI, a CHD, or an ISO in a zip or a 7z: xemu can not open these. The plugin makes an XISO from it the first time, in Emulators\Nixx-Xemu\discs. That can take a minute. The next time, the game starts at once. The oldest copies are deleted when the folder gets too big.
  • Each game runs on its own console. To quit, press Escape.

Keys

xemu's keys can't be changed. The plugin names its four snapshot keys Slot 1 to Slot 4 (F5 to F8, if you haven't set them yourself), and the running script adds the pack's usual keys on top:

KeyDoes
F2Save a snapshot in the current slot
F4Load the current slot
F6 / F7Previous / next slot (1 to 4, back to 1 at every launch)
F11Full screen (xemu's own; Ctrl+Alt+F too)
EscQuit

xemu's own keys still work: F5-F8 load a slot, Shift+F5-F8 save it. xemu's popup menu, normally on F2, is still on the right click. The pause screen's Save / Load State use Slot 1. A snapshot stays in the game's console; to see it in LaunchBox, turn on xemu's snapshots as savestates in the Nixx window.

Each savestate file gets xemu's own picture of it beside it, as a PNG of the same name (slot-1.xemustate.png).

Playing online (Insignia)

Insignia brings back Xbox Live for the original Xbox. The plugin plays online games on one Live console, kept apart from the games' own consoles. Once:

  1. Get a console disk that has Microsoft's dashboard (5960) - a .qcow2, or a raw image of your Xbox's disk. xemu's own dashboard has no Xbox Live section, and Microsoft's is not ours to ship.
  2. In Tools > Nixx Integration Plugins Configuration, page xemu, card Xbox Live (Insignia): Import a console disk... It is copied; your file is never written. If the disk comes from a real Xbox, import its eeprom.bin too.
  3. Run Insignia setup: the Setup Assistant (downloaded from Insignia) starts on the Live console. Troubleshoot checks it, Register Xbox registers it.
  4. Ask insignia.live for a subscription code (by e-mail). Start the Live console, go to Xbox Live and make your account: gamertag, the code, the same e-mail, and the test card 4111 1111 1111 1111. If the Setup Assistant said the DNS was wrong, set 46.101.64.175 in Settings > Network.

Then, in a game's window (right-click, Nixx-Xemu : Options..., tab Console & disc), tick Play online (Insignia). That game now starts on the Live console with xemu's network on. Its updates come from Insignia and stay on that console. No save and no savestate of it are handled while it is in Live mode: its own console and its save stay as they were.

Only the games in Insignia's own list get this option - the plugin knows them by their title id, from that list (downloaded again once a day, a copy of it built in). For those games, right-click (LaunchBox) or the game's menu (Big Box) also offers Nixx-Xemu : Run with Insignia: it starts the game online once, whatever its option says - shown only when a Live console is set up.

The disk you choose is copied once into the emulator's live folder and kept clean: the Live console writes only into a differential image over that copy. The EEPROM, when you choose one (optional), is copied too. Without one, the Live console's EEPROM is made once, with your console's identity, and never changes after: it is the console Insignia registered.

Saves

A game's console is one small file, hdd\games\<game id>.qcow2. It holds everything the game saved. LaunchBox's Backup and Restore work with that file. Deleting the save gives the game a fresh console next time.

The other emulators' saves

  • A game's Game Saves also shows the saves the other emulators keep for it - one played with Launch With, or before the game moved to xemu: RetroArch's, Dolphin's, PCSX2's and the other Nixx plugins'. Each card names its emulator.
  • They are backed up with xemu's when the game quits, and a restore puts each one back where its own emulator reads it, never into xemu's folders.
  • Two installs of one emulator (two folders) keep their cards apart; when a restore cannot tell which install a card is for, it asks you.
  • Turned off on the Compatibility page of the Nixx window (Saves of every emulator), a game shows only xemu's saves, as in LaunchBox. The Nixx-Saves guide tells the same for games set to LaunchBox's own integrations.

Limits and things to know

  • A game does not see the saves of another game, because each one has its own console. On the Xbox, very few games need that.
  • The other Xemu plugin, the one that comes with LaunchBox, keeps working with its own emulator entry. This plugin only looks after Nixx-Xemu.

If something goes wrong

  • The plugin's log: %LOCALAPPDATA%\lb-integrations-plugins\xemu.log (General tab: "Open the logs folder").
